# main.js — краткое описание

## Общая структура

Файл управляет **интерактивным графиком ВАХ мемристора** на фронтенде.

---

## Основные функции

### 1. `loadHistory()`
- Загружает историю запросов с сервера (`/history`)
- Отображает её в таблице (время + количество точек)
- Вызывается при загрузке страницы и каждые 5 секунд

### 2. `showError(message)`
- Показывает всплывающее сообщение об ошибке
- Через 3 секунды автоматически исчезает

### 3. `initEmptyPlot()`
- Рисует пустой график при загрузке страницы
- Оси фиксированы: X: -6…6 В, Y: -2…2 А
- Ждёт нажатия кнопки "Снять ВАХ"

### 4. `startMeasurement()` — **главная функция**
- Блокирует кнопку на время измерения
- Отправляет POST-запрос на `/measure-stream`
- **Получает точки по очереди** (не все сразу)
- Каждую новую точку **сразу отображает** на графике
- Автоматически масштабирует оси под новые данные
- После завершения обновляет таблицу истории

---

## Поток данных

```
Кнопка → startMeasurement() → fetch(/measure-stream)
                                    ↓
                            Сервер шлёт точки по одной
                                    ↓
                    Каждая точка → Plotly.update() → график обновляется
                                    ↓
                            Приём DONE → loadHistory()
```

---

## Дополнительно

- **`isMeasuring`** — флаг, запрещающий повторное нажатие во время измерения
- **Автообновление истории** — раз в 5 секунд (чтобы видеть запросы других пользователей)
- **Обработка ошибок** — сетевые сбои, занятость сервера (HTTP 409)

---

## Зависимости

- **Plotly.js** — отрисовка графика (CDN)
- **Fetch API** — HTTP-запросы
- **Stream reading** — `response.body.getReader()` для приёма точек по одной
