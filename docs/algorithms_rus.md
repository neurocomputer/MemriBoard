## Работа с алгоритмами

### Создание и добавление алгоритмов

Создание и добавление алгоритмов осуществляется на [окне конфигурации эксперимента](README_rus.md#конфигурация-эксперимента). Сохраненные алгоритмы указаны в правой части окна, для добавления алгоритма в план эксперимента необходимо дважды нажать на его название. На этом же окне создать новый алгоритм. Двойной клик по алгоритму в плане эксперимента открывает [окно редактирования алгоритма](#окно-редактирования-алгоритма).

___

### Окно редактирования алгоритма

В верхней части окна можно ввести имя алгоритма, [показать встроенные функции](#встроенные-функции), и открыть эту инструкцию. В правой нижней части окна расположены кнопки проверки алгоритма, а также две кнопки сохранения: кнопка **сохранить** сохраняет внесенные изменения в план эксперимента, кнопка **сохранить в папку algorithms** сохраняет алгоритм и в план эксперимента, и в папку `MemriBoard/algorithms`. Изменение названия алгоритма сохраняет его в новый файл.

Алгоритмы призваны вызывать различные [тикеты](README_rus.md#конфигурация-эксперимента) в зависимости от текущего состояния мемристора. Тикеты, которые вызываются из алгоритма по ссылке на файл (или по названию тикета), привязываются к файлу алгоритма на этапе проверки и могут быть экспортированы из файла алгоритма при помощи кнопки **Экспорт тикетов**. По умолчанию алгоритм берет тикеты из папки `MemriBoard/tickets`. Если тикеты экспортированы в другую папку, необходимо указать ее в аргументе всех функций, ссылающихся на тикеты в ней.

___

### Написание алгоритма

В центральной левой части окна расположен редактор алгоритма. Сам алгоритм пишется на языке Python, что позволяет использовать ветвления и циклы. Можно также импортировать внешние модули (например, `numpy`), создавать переменные, и т.д.

Алгоритм должен определять функцию **`algorithm()`**, не содержащую аргументов. При проверке и исполнении алгоритма эта функция трансформируется в генератор тикетов, используемый в эксперименте. Перед сохранением алгоритма можно нажать кнопку **Проверить**, запускающую алгоритм в тестовом режиме и выводящую возникающие ошибки в поле **Результат проверки**.

Для взаимодействия с параметрами мемристора и тикетами созданы [встроенные функции](#встроенные-функции), которые можно использовать в алгоритмах.

___

## Встроенные функции

Встроенные функции, которые можно использовать в алгоритмах, делятся на две категории.

### 1. Вспомогательные функции

Эти функции взаимодействуют с параметрами мемристора, или позволяют пользователю взаимодействовать с тикетами из алгоритма:

___

### `last_resistance()`

Получить последнее измеренное сопротивление мемристора. Значение этой переменной обновляется автоматически после завершения каждого тикета.

***Возвращает:***

- **последнее сопротивление** (`float`)

Пример использования доступен в [примере с ветвлением](#алгоритм-с-ветвлением-example_if).

___

### `set_last_resistance(сопротивление)`

Вручную устанавливает переменную последнего сопротивления. Значение этой переменной обновляется автоматически после завершения каждого тикета. Эта функция не возвращает значений.

***Аргументы:***

- **сопротивление** (`float`): сопротивление, присваивающееся переменной.

___

### `get_ticket_dict(название, путь_к_папке[опц] = None)`

Получить тикет или эксперимент в виде словаря (`dict`) по его названию.

***Аргументы:***

- **название** (`str`): название тикета.
- **путь_к_папке** (`str | None`, опциональный): путь к папке с тикетом. Если этот аргумент равен `None`, используется стандартная папка для тикетов (`MemriBoard/tickets`). По умолчанию равен `None`.

***Возвращает:***

- **тикет** (`dict`): тикет в виде словаря.

Пример использования доступен в [примере с циклом](#алгоритм-с-циклом-for-example_for_cycle).

___

### 2. Функции, отправляющие тикеты

Эта группа функций отправляет тикеты на плату во время выполнения алгоритма. Они не возвращают значение пользователю. При компиляции алгоритма они трансформируются в генераторы, поэтому **нельзя использовать их в конструкциях с присвоениями: конструкции типа `x = send_ticket()` или `[send_ticket() for _ in range(5)]` запрещены.** Все функции этого вида следует писать на отдельной строке кода, например:

```python
for _ in range(5):
    send_ticket('iv-curve')
```

___

### `send_ticket(название, путь_к_папке[опц] = None)`

Отправить тикет по его названию. Не следует использовать эту функцию для отправки эксперимента (последовательности тикетов), для этого нужно использовать `send_experiment()`. Функция не возвращает значений.

***Аргументы:***

- **название** (`str`): название тикета.
- **путь_к_папке** (`str | None`, опциональный): путь к папке с тикетом. Если этот аргумент равен `None`, используется стандартная папка для тикетов (`MemriBoard/tickets`). По умолчанию равен `None`.

___

### `send_ticket_dict(тикет)`

Отправить тикет в виде словаря (`dict`). В связке с функцией `get_ticket_dict()` можно использовать эту функцию для коррекции параметров эксперимента в процессе выполнения. Не следует использовать эту функцию для отправки эксперимента (последовательности тикетов), для этого нужно использовать `send_experiment_dict()`. Функция не возвращает значений.

***Аргументы:***

- **тикет** (`dict`): тикет в виде словаря.

Пример использования доступен в [примере с циклом](#алгоритм-с-циклом-for-example_for_cycle).

___

### `send_experiment(название, путь_к_папке[опц] = None)`

Отправить эксперимент (последовательность тикетов) по его названию. Не следует использовать эту функцию для отправки одного тикета, для этого нужно использовать `send_ticket()`. Функция не возвращает значений.

***Аргументы:***

- **название** (`str`): название эксперимента.
- **путь_к_папке** (`str | None`, опциональный): путь к папке с экспериментом. Если этот аргумент равен `None`, используется стандартная папка для тикетов (`MemriBoard/tickets`). По умолчанию равен `None`.

Пример использования доступен в [примере с ветвлением](#алгоритм-с-ветвлением-example_if).

___

### `send_experiment_dict(эксперимент)`

Отправить эксперимент в виде словаря (`dict`). В связке с функцией `get_ticket_dict()` можно использовать эту функцию для коррекции параметров эксперимента в процессе выполнения. Не следует использовать эту функцию для отправки одиночного тикета, для этого нужно использовать `send_ticket_dict()`. Функция не возвращает значений.

***Аргументы:***

- **эксперимент** (`dict`): эксперимент в виде словаря.

___

### `measure_resistance()`

Измерить сопротивление мемристора. Функция отправляет тикет, использующийся в приложении для измерения сопротивления (он указывается в `settings.ini/gui/measure_ticket`). Функция не возвращает значений.

Пример использования доступен в [примере с ветвлением](#алгоритм-с-ветвлением-example_if).

___

## Примеры алгоритмов

Следующие два примера алгоритмов доступны по умолчанию на [окне конфигурации эксперимента](README_rus.md#конфигурация-эксперимента).

### Алгоритм с ветвлением (example_if)

Пример реализации алгоритма с ветвлением: использует конструкцию `if` для отправки разных тикетов на основании последнего измеренного сопротивления.

Алгоритм ссылается на эксперименты в виде .json файлов, их нужно экспортировать в какую-нибудь папку при помощи кнопки 'Экспорт тикетов' и указать в функции `send_experiment` аргументом `folder_path`. Если экспортировать в стандартную папку `tickets`, то аргумент можно не указывать.

```python
def algorithm():
    # Измеряем сопротивление
    measure_resistance()
    # Делаем эксперимент в зависимости от измеренного сопротивления
    if last_resistance() > 10000:
        # Делаем SET
        send_experiment('Experiment_SET')  # Развертка от 0 до -2 В
    else:
        # Делаем RESET
        send_experiment('Experiment_RESET')  # Развертка от 0 до +2 В
```

___

### Алгоритм с циклом for (example_for_cycle)

Пример реализации алгоритма с циклом `for` и изменением параметров тикетов.

Алгоритм реализует двойную развертку: первичная развертка по напряжению идет
в тикете `iv_curve`, вторичная развертка реализуется циклом `for`. Вторичная развертка по граничному напряжению &mdash; от 1 до 2.5 вольт, 5 точек.

```python
import numpy as np  # Импортируем numpy

# Создаем вспомогательную функцию изменения напряжения в тикете
def change_ticket_voltage(ticket, voltage):
    ticket['params']['stop_dir'] = voltage
    ticket['params']['stop_rev'] = voltage
    return ticket


# Функция алгоритма
def algorithm():
    # Создаем массив напряжений для вторичной развертки
    v_array = np.linspace(1, 2.5, 5, dtype=float)
    # Получаем тикет как dict для редактирования
    base_ticket = get_ticket_dict('iv-curve')
    # Делаем цикл for
    for voltage in v_array:
        # Редактируем тикет
        ticket = change_ticket_voltage(base_ticket, voltage)
        # Выполняем тикет
        send_ticket_dict(ticket)
```
